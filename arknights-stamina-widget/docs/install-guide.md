# 华为 Mate 70 Pro+ 安装与使用图文教程

适用：鸿蒙 4.x（含 Android 兼容层，"半血鸿蒙"）→ 可直接侧载 APK；鸿蒙 NEXT（纯血）请见 [harmonyos-port.md](harmonyos-port.md)。

## 第 1 步：把 APK 传到手机

任选其一：

- 数据线：连电脑后在「文件管理」→ 内部存储 → `Download` 粘贴 `app-debug.apk`；
- 微信/QQ：「文件传输助手」发送，手机上点开文件；
- 网盘/邮件自取。

APK 位置（本机构建）：

```
app/build/outputs/apk/debug/app-debug.apk
```

## 第 2 步：允许安装未知来源

1. 用「文件管理」打开 APK；
2. 弹出"该应用不允许安装未知来源应用"时 → 点 **设置**（或 **允许**）；
3. 在列表中找到 **文件管理**（你当前正在用的应用）→ 打开「允许安装未知来源应用」；
4. 返回点击 APK → **继续安装** → 完成。

> 若提示"存在风险/检测"，选择 **仍然安装**。纯个人工具无任何敏感权限。

## 第 3 步：打开并绑定账号

打开「明日方舟体力卡」，三种绑定方式：

### 方式 A1：手机验证码（推荐）

1. 输入**注册方舟的鹰角账号手机号** → 「获取验证码」；
2. 收短信后填入验证码 → 「登录并绑定」；
3. 看到「已绑定：博士昵称（uid）」即成功。

自动完成：验证码 → 鹰角 token → OAuth code → 森空岛 cred+token → 读取默认官服角色。

### 方式 A2：手机号 + 密码

输入同一手机号与**鹰角账号登录密码** → 「密码登录并绑定」。

> 密码仅用于一次性换 token：直连鹰角官方服务器，**不保存、不上传第三方**，操作完成后密码框自动清空。

### 方式 B：粘贴 token

1. 电脑浏览器登录 [森空岛 www.skland.com](https://www.skland.com)（或 user.hypergryph.com）；
2. F12 → Network → 刷新页面，找到任意 `web-api.skland.com` 请求 → 响应里的
   `data.content` 即"鹰角 token"（一串大写字母数字）；复制整段 JSON 或只复制 content 值；
3. 手机 App 里粘贴 → 「使用此凭证」。

> 找不到？也可以抓包森空岛 App 登录后的 `as.hypergryph.com` token，或参考
> [nonebot-plugin-skland 凭证获取说明](https://docs.qq.com/doc/p/2f705965caafb3ef342d4a979811ff3960bb3c17)。

## 第 4 步：把小组件加到桌面

1. 回到桌面，**长按空白处**（或用双指在桌面捏合）；
2. 底部弹出工具栏 → 选 **服务卡片 / 卡片 / 窗口小工具**（鸿蒙 4.x 上入口名可能为"窗口小工具"）；
3. 下滑找到 **体力卡 · 明日方舟**（深蓝底、金色沙漏图标）；
4. 长按拖到桌面，用四角拉成 **2×2**；
5. 几秒内卡片即显示当前理智；**点按卡片**可打开 App 立即刷新。

## 第 5 步（可选）防杀后台 / 提升及时性

华为系统默认会限制后台，若发现卡片长时间不更新：

- 打开 App → 最近任务（多任务）→ 将「明日方舟体力卡」卡片**下拉加锁**；
- 设置 → 应用 → 应用启动管理 → 明日方舟体力卡 → 关掉"自动管理" → 手动开启 **自启动 / 后台活动**；
- 设置 → 应用 → 明日方舟体力卡 → 电池 → 选择**不限制**；
- 卡片数值"实时感"来自本地推算：每 15 分钟静默同步一次拿到服务器「回满时刻」，期间本地按 1 理智/6 分钟推进。想更准就随时点一下卡片。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 绑定提示"验证码错误/发送失败" | 确认手机号是**鹰角账号通行证**手机号（与游戏绑定一致）；等待 60 秒后重发 |
| 同步提示"接口错误 code=…" 含 登录/token/凭证 | token 过期：App 内「解绑」后重新绑定 |
| "设备指纹获取失败" | 首次需联网访问 fp-it.portal101.cn（数美服务）；切换 Wi-Fi/流量重试 |
| 卡片一直显示未绑定 | 绑定成功后**重新添加**一次小组件，或打开 App 点「立即刷新体力」 |
| 数字偏大/进度满 | 少数账号接口未回传上限字段，App 按"82+等级、封顶135"估算；不影响剩余/回满显示 |
| 华为提示"病毒/风险" | 侧载应用正常提示，仅个人使用可继续安装 |

## 权限说明

- `INTERNET`：查询体力/登录所需；
- `RECEIVE_BOOT_COMPLETED`：重启后恢复定时同步；
- 无存储、通讯录、定位、短信读取等任何多余权限。
